# Главная и командная очередь

«Главная» открывается после входа и закреплена первой в меню. Раскладка общая для команды. Её редакторы перечислены через запятую в `DASHBOARD_EDITORS` (по умолчанию `16538296`; локальная универсальная учётка может редактировать при отсутствии явной настройки).

При создании виджета выбирается, кому он виден: **«Для всех»** — общий виджет команды, создают и меняют только редакторы; **«Личный»** (значок замка) — виден и меняется только владельцем, создать его может любой пользователь. Раскладка у каждого своя для личных виджетов: сохранение меняет только общие (у редактора) и собственные личные, чужие личные не затрагиваются; при наложении личные сдвигаются под общие. Очередь и отметки личного счётчика доступны только владельцу.

Два типа виджетов: **Список** и **Счётчик**. Внутри списка переключаются таблица, кольцевая диаграмма и гистограмма. Задайте название, любой JQL и период создания (условия JQL, сегодня, 7 дней либо даты). Списки фильтруются и сортируются как Jira tool. У диаграммы выбираются поле группировки и метрика: количество либо сумма значения поля. Доступны пять палитр и свои цвета отдельных групп. Нажатие на сегмент или группу открывает задачи этой группы.

Кнопка **«Колонки»** рядом с переключением представления открывает тот же выбор полей, что используется в Jira tool: поиск, группы Jira/Shark, множественный выбор. Поля идут в порядке выбора; номер всегда остаётся первым. Нажмите «Применить», чтобы сохранить состав и порядок для команды. В развёрнутом списке и очереди счётчика есть такой же выбор; он меняет те же настройки виджета. В режиме раскладки изменения сохраняются и отменяются вместе с раскладкой. В настройках виджета-списка также есть раздел «Колонки списка». Можно выбрать любые поля каталога Jira, локальные поля ST и собственные поля сохранённых списков. Поиск учитывает выбранные колонки, фильтры работают по отдельным значениям множественного поля, числовые поля сортируются по числам. Настройка доступна редакторам общей Главной. При ошибке сохранения выбор остаётся открытым, прежняя конфигурация сохраняется.

В заголовке колонки **«Тип задачи»** есть переключатель **значок / значок с названием**. Он работает и в Jira tool, и в стандартных таблицах задач, включая Главную. Полное название остаётся в подсказке значка; сортировка и фильтры используют исходное название типа. Выбор личный, запоминается в браузере и синхронизируется между его вкладками. Ручная ширина колонки сохраняется при переключении.

В диаграммах доступны также **поля ST**: этап, тестировщик и направления, папки, требования, микросервисы, дефекты, передачи на ИФТ/ПСИ и собственные поля списков. Числовые метрики включают плановые часы тестировщика и направлений. «Источник полей ST» выбирает конкретный сохранённый список или все списки. При разных числовых значениях одной задачи в нескольких списках показывается предупреждение: выберите один источник. Настройка виджета общая, но значения ST читаются из существующих данных Jira tool **текущего браузера**; они не становятся серверной общей базой. На другом компьютере требуется перенести данные Jira tool. Отсутствующий список обозначается явно.

Размеры уточнены по рисунку владельца: **S — маленький квадрат 170×170 px, M — квадрат 346×346 px, L — широкий 698×346 px, XL — 1050×522 px, XXL — вся ширина сетки ×522 px**. Число столбцов зависит от окна, а физическая ячейка фиксирована (38 px, шаг 44 px): S не раздувается на широком мониторе. На узком экране большие списки ограничиваются доступной шириной; S остаётся квадратом 170 px. **Счётчик всегда только S, изменение размера отключено**; его можно перемещать. У списка размер выбирается и меняется вручную; ручной размер показывается отдельно от пресетов.

Кнопка «Раскладка» включает настройку: тяните ручку в шапке для перемещения и нижний правый угол списка для изменения размера. На сфокусированной ручке работают стрелки клавиатуры. При пересечении другие виджеты сдвигаются вниз. Свободные промежутки сохраняются. «Сохранить» применяет раскладку для команды, «Отмена» возвращает исходную. Старые диаграммы становятся представлениями списка, прежние размеры мигрируют в схему `gridVersion=2`, счётчики — S; очереди и отметки обработки сохраняются. Адаптация к узкому окну не записывает общую раскладку сама.

Счётчик — отдельный виджет из **названия и огромной цифры**; ноль зелёный. Число подстраивается под размер карточки. Служебные кнопки доступны в режиме раскладки. После обнаружения задача остаётся в очереди, даже если выходит из периода/фильтра. Нажмите число для открытия стандартной таблицы. Название задачи открывает карточку, ключ — Jira. «Обработано» доступно в строке и для выбранных задач; отметка общая для команды, автор и время видны в обработанных. Отметку можно отменить. Она не меняет статус Jira. Разные счётчики имеют независимые очереди обработки. При ошибке сохраняется прежнее число; заголовок/рамка показывают предупреждение, подробности — при наведении и в открытой очереди. Отсутствие первой загрузки обозначается тире, не ложным нулём.

Смена **статуса Jira после обнаружения задачи** автоматически отмечает её обработанной во всех счётчиках, которые уже её отслеживают. Проверяются текущий статус и доступная история переходов, в том числе для задач, вышедших из JQL. В обработанных видны причина и переход; отметку можно отменить. Старые переходы до обнаружения или до отмены отметки не обрабатывают задачу повторно. Обычное изменение темы, исполнителя и других полей не считается обработкой. Переход через Shark запускает обновление виджетов, внешнее изменение подхватывается очередным опросом. Если Jira не вернула историю, смену с возвратом в прежний статус между опросами обнаружить нельзя.

Во всех стандартных таблицах задач доступны изменение одной задачи и кнопка «Изменить» рядом со сменой статуса при множественном выборе. Форма сразу открывает используемые поля Jira, включая поля регистрации, доступные на экранах редактирования: выбирать поля из отдельного меню не нужно. Одиночные и одинаковые массовые значения заполнены; разные помечены и остаются без изменений. Отправляются только изменённые поля. Перед сохранением сверяется editmeta каждой задачи; отсутствующие поля не отправляются, результаты видны отдельно по задачам. Сохранение выполняется фоном с прогрессом; можно отменить оставшиеся задачи. Закрытие окна не отменяет начатую операцию. Пустое поле не означает очистку — для очистки есть отдельный флажок.

Бэкенд обновляет виджеты каждые 30 секунд при работающем приложении (один API worker). Браузер можно закрыть. Обычный опрос лёгкий: по всему JQL запрашиваются только статус и дата изменения, полные поля и история переходов догружаются лишь для новых и изменившихся задач. Полная выборка выполняется раз в 15 минут и сразу после смены колонок или полей диаграммы. При недоступности Jira сохраняются данные и время последнего успешного чтения; показывается ошибка. Один поиск ограничен 20 000 задач, превышение явно отмечается как неполная выдача. Сузьте JQL. Счётчик сохраняет уже найденные задачи и не обещает обнаружить задачу, которая успела появиться и выйти из JQL между опросами либо во время остановки сервера. Для критичных очередей используйте устойчивый JQL, например по созданию, а не только по текущему статусу.

`data/dashboard.json` хранит раскладку, очередь и историю отметок. Запись атомарная; одновременное обновление не стирает обработку, версия раскладки защищает от потери чужих настроек. При переносе хоста сохраните этот файл. Удаление карточки не стирает накопленную историю из файла. Секретов в нём нет.

Резервная копия раздела **«Главная»** переносит этот файл целиком: настройки виджетов и счётчиков, фильтры, периоды, колонки, диаграммы, цвета, размеры, позиции, задачи и отметки обработки. Браузер добавляет ширины таблиц и личные настройки Эфира. При загрузке режим **«Дополнить»** включён по умолчанию: существующие настройки и отметки сохраняются, недостающие задачи и виджеты добавляются без дублей; новые карточки размещаются без наложения. **«Перезаписать»** заменяет данные представленными в файле. Версия раскладки обновляется в обоих режимах; старый редактор или фоновый запрос Jira не может записать поверх восстановленного состояния. Для переноса самих значений ST добавьте раздел Jira tool или выгрузите все разделы. Личные виджеты тоже попадают в копию вместе с владельцем, но при загрузке добавляются только тому, чьи они: виджеты других пользователей пропускаются, а уже существующие чужие личные виджеты не удаляются и при «Перезаписать». Подробнее — [перенос](../MIGRATION.md).

Панель **Эфир** находится справа, отделена от сетки и прокручивается независимо. Разделитель меняет ширину мышью или стрелками; кнопка разворачивает панель на всю рабочую область. На телефоне она размещается под виджетами. Три вкладки: **Чат / Почта / Встречи**, все через одно MCP-подключение Эфира. Для каждой отдельно задаются коллеги и/или слова/фразы. Совпадение коллеги либо любого слова включает запись в ленту, слова выделяются в тексте и подсвечивают карточку. Фильтры и ширина личные, сохраняются в браузере и входят в резервную копию Главной. В мок-режиме есть демонстрации трёх каналов. Если реальный MCP не объявляет безопасный инструмент чтения канала, выводится недоступность, а не ложное сообщение об отсутствии записей. Только чтение, обновление раз в 30 секунд.

Подключение также доступно через «Настройки → Интеграции → Эфир». Сессию хранит бэкенд, лента использует вошедшую в Эфир учётную запись; показывать следует только допустимые для команды данные. Профиль браузера изолирован от обычных окон, session-cookie зашифрована. Подробнее: [Эфир MCP](efir-mcp.md).
