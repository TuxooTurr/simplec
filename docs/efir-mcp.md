# Эфир на «Главной»: чат, почта и встречи через один MCP

Отдельная правая панель «Главной» содержит вкладки «Чат / Почта / Встречи».
По уточнению владельца от 21.11.2026 все три используют один MCP-сервер Эфира
(efir.sber.ru) и одну авторизацию. Лента читается инструментами чтения; ответ в чат
и на письмо — только по нажатию «Отправить» / «Ответить» (см. «Участники, переписка и ответы»).
Для каждой вкладки отдельно настройте отслеживаемых коллег и слова/фразы;
совпадение коллеги или любого слова включает запись в ленту. Совпадения слов
подсвечиваются, карточка открывает подробности. Настройки личные, в браузере.
Ширина панели изменяется разделителем; есть разворачивание на всю рабочую область.

## Два подключения

| Где | Адрес | Зачем |
|---|---|---|
| GigaCode CLI/Desktop | `https://efir.sber.ru/api/platform/api/v1/mcp/mcp/` (HTTP) | Агент читает Эфир сам; подключение регистрируется отдельно в настройках ГигаКод; проверьте `gigacode mcp list` |
| Бэкенд Shark | тот же URL | Лента чата «Эфир»; подключение по кнопке (см. ниже) |

## Подключение по кнопке (основной путь)

1. Откройте в Shark **Настройки → Интеграции → Эфир · Главная** или нажмите
   кнопку прямо в панели чата на «Главной».
2. Нажмите **«Подключить через браузер»** — откроется окно `efir.sber.ru`.
3. Войдите как обычно (сертификат / корпоративный SSO).
4. Бэкенд сам заметит вход, проверит cookie живым вызовом MCP, сохранит сессию
   в зашифрованное хранилище Shark (`data/ether_cookies.json`, 0600) и закроет
   окно браузера. Окно Shark покажет «Подключено».

Что происходит под капотом: Playwright с постоянным профилем
(`~/.simpletest/ether-web/profile`). Браузер для входа определяется
автоматически: **Сбербраузер** (`/Applications/SberBrowser.app`) или Google
Chrome; явный путь можно задать в `MCP_WEB_BROWSER_PATH`. Пароль нигде не
вводится в Shark; повторное нажатие кнопки при живой сессии завершается
мгновенно, без окна.

Если сессия истекла (в ленте ошибка 401) — нажмите кнопку снова.

## Серверный контур: ETHER_MCP_HEADERS (запасной путь)

На сервере без браузера заголовки авторизации задаются окружением:

```
ETHER_MCP_HEADERS=Cookie: <значение>
```

Заголовки — по одному «Имя: значение» на строку. Cookie берётся из devtools
браузера (Network → запрос к `/api/platform/…` → Request Headers → Cookie).
Cookie из хранилища (после входа по кнопке) имеют приоритет над окружением.

## Переменные окружения

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `ETHER_MCP_HEADERS` | — | Заголовки авторизации из окружения (если нет сохранённой сессии) |
| `ETHER_MCP_URL` | боевой адрес MCP | Адрес MCP-сервера Эфира |
| `ETHER_FEED_LOOKBACK_HOURS` | `72` | Глубина ленты, часов (1…720) |
| `ETHER_DIALOGS_TTL` | `60` | Кэш списка диалогов, сек |
| `ETHER_MSG_TTL` | `90` | Кэш сообщений одного диалога, сек |
| `ETHER_BUDGET` | `8` | Сколько диалогов обновлять за цикл опроса |
| `ETHER_REQUEST_TIMEOUT` | `30` | Таймаут одного вызова MCP, сек |
| `ETHER_FEED_LIMIT` | `100` | Максимум сообщений в ответе |
| `ETHER_MAIL_TOOL`, `ETHER_MEETINGS_TOOL` | По объявленным инструментам чтения | Точное имя инструмента почты / встреч из `tools/list` |
| `ETHER_MAIL_ARGS`, `ETHER_MEETINGS_ARGS` | `{}` | JSON дополнительных аргументов чтения по реальному контракту |
| `ETHER_BROWSER_PROFILE` | `~/.simpletest/ether-web/profile` | Профиль браузера входа |
| `MCP_WEB_BROWSER_PATH` | авто: Сбербраузер → Chrome | Явный путь к браузеру входа |

Без учётных данных эндпоинт честно отвечает `configured: false`, и панель
показывает кнопку подключения.

## Контракт почты и встреч

Предоставленная ранее документация подтверждает диалоги/сообщения Эфира. Наличие
почты и встреч в целевой версии MCP ещё нужно проверить внутри контура. Shark
ищет известные имена инструментов чтения; если имя другое или подходит несколько,
задайте его явно через переменные выше. Инструмент должен объявлять
`readOnlyHint=true`; инструменты записи не вызываются. Аргументы передаются только
из объявленной схемы, обязательные проверяются. Не добавляйте вторую учётку:
используются тот же `ETHER_MCP_URL`, Cookie/SSO и клиент.

Клиент понимает массивы `messages/emails/events/meetings/items/results`, в том
числе вложенные в `data`. Для почты: `id`, `subject/title`, `text/body/preview`,
`sender/from`, `date/received_at/created_at`; для встреч: `id`, `title/name`,
`description/text`, `organizer`, `attendees`, `start/start_time`, `end/end_time`,
`location`. Если реальная форма отличается, адаптируйте нормализацию и аргументы
по обезличенному контракту. Отсутствие инструмента показывается как недоступность
канала, не как нулевая выдача. Мок-данные не подтверждают реальный контракт.

Сырые результаты почты/встреч кешируются на процесс на `ETHER_MSG_TTL`, фильтрация
коллег/слов выполняется по общему кешу без повторного чтения для каждой вкладки
браузера. Бюджет до 20 вызовов чтения в минуту общий с сообщениями чата; реальные
лимиты почты/встреч также сверяются при приёмке. По умолчанию почта — за 72 часа,
встречи — в окне ±72 часа; параметр `ETHER_FEED_LOOKBACK_HOURS` меняет окно
нормализации, фактические аргументы источника сверяются отдельно.

## Отчёты виджетов

Редактор виджета с подключённым Эфиром может сохранить расписание отправки выбранным получателям. Фоновая задача использует тот же инструмент отправки и проверяет владельца подключения перед доставкой. Формат сообщения — текст, цветные маркеры статусов и URL запроса Jira. ## Участники, переписка и ответы

- **Кого отслеживать.** В настройках вкладки начните вводить фамилию, название чата или группы — Shark ищет в Эфире:
  чаты и группы — по диалогам аккаунта (`get_dialogs`), коллег — инструментом поиска, если подключение его объявляет.
  Добавить можно только найденное. Если поиска людей нет, свой вариант добавляется с пометкой «без проверки».
  Отслеживаемый участник совпадает с автором сообщения или с названием диалога (личный чат, группа).
- **Переписка.** Карточка чата открывает диалог (`get_messages`, 50 последних) и поле ответа.
- **Почта.** Карточка письма открывает письмо целиком и ответ, если подключение объявляет чтение письма и ответ;
  иначе показан текст из ленты.
- **Встречи.** Без настроенного отслеживания показываются все встречи окна.
- **Кто может отвечать.** Сессия Эфира одна на сервер, поэтому писать может только пользователь Shark, который подключил
  Эфир (запоминается при нажатии «Подключить», `data/ether_owner.json`; при подключении из окружения — `ETHER_OWNER_LOGIN`).
  Остальные видят переписку без поля ответа.
- **Инструменты.** Берутся из `tools/list` по известным именам или по точному имени из окружения:

| Что | Переменная | Известные имена | Требование |
|---|---|---|---|
| Поиск коллег | `ETHER_SEARCH_TOOL` | `search_users`, `chat_search_users`, `find_users`, `search_contacts`… | `readOnlyHint=true` |
| Ответ в чат | `ETHER_SEND_TOOL` | `send_message`, `chat_send_message`, `chat_send`, `messages_send` | не `destructiveHint=true` |
| Письмо целиком | `ETHER_MAIL_READ_TOOL` | `mail_get_message`, `get_email`, `mail_read_message`… | `readOnlyHint=true` |
| Ответ на письмо | `ETHER_MAIL_REPLY_TOOL` | `mail_reply`, `reply_email`, `mail_send_reply`… | не `destructiveHint=true` |

  Аргументы передаются только объявленные в схеме инструмента. Наличие и контракт инструментов поиска и записи
  внутри контура не подтверждены — сверьте `tools/list` при приёмке; без инструмента функция честно недоступна.

## Ограничения

- **Rate-limit платформы**: `get_dialogs` до 10 вызовов/мин, `get_messages`
  до 20/мин на аккаунт. Кэши выше держат частоту заведомо ниже лимита при
  любом числе открытых вкладок Shark. Фронтенд опрашивает каждые 30 секунд,
  минимальный TTL сообщений — 90 секунд. Просматриваются 25 недавних диалогов;
  при бюджете 8 за цикл полный обход занимает несколько циклов. Сначала читаются
  ещё не полученные и самые старые кеши, чтобы дальние диалоги не оставались без
  обновления. Лента не является полной выгрузкой всей переписки.
- **Cookie недолговечна**: при перевыпуске SSO-сессии (401) подключите заново
  по кнопке или обновите `ETHER_MCP_HEADERS`.
- **Приватность**: cookie даёт доступ к переписке от вашего имени. Не
  пересылайте её в чаты и тикеты; файлы сессий исключены из git.
- Видны только те диалоги, в которых состоит аккаунт, вошедший в Эфир;
  конфиденциальные сообщения приходят с пометкой «скрыто».

В этой реализации лимит сообщений дополнительно контролируется скользящим бюджетом 20 вызовов/минуту на процесс, диалогов — 10/минуту. Сбои не очищают уже показанную ленту. Поиск Сбербраузера поддерживает macOS и PATH Linux. На сервере без графического браузера используйте `ETHER_MCP_HEADERS` из секретов окружения. В репозитории Shark `.env` исторически отслеживался: `.gitignore` сам по себе не удаляет уже отслеживаемый файл. Не записывайте в него Cookie/пароли; используйте окружение запуска или зашифрованное хранилище.

Бюджет `ETHER_BUDGET` общий на цикл кеша диалогов: повторный опрос вкладки не получает дополнительные 8 вызовов. Время диалогов разбирается как дата (включая вложенный `last_message` и часовые пояса); инструменты MCP ищутся по страницам `tools/list`.
